EXAM BANK | B(ChatGPT) UI + 2027학년도 LEET 추리논증 40문항
==========================================================

1. 설치 및 배포 (GitHub Pages)
---------------------------------
(1) ZIP 파일을 PC에 압축 해제합니다.
(2) 압축 해제한 EXAM_BANK_프로젝트 폴더의 '안쪽 내용'을 통째로 GitHub 저장소 parkexam/pass 최상위에 업로드하세요.
    올려야 할 항목: index.html, css/, js/, data/, assets/, README_설치방법.txt
    ZIP 파일 하나만 업로드하면 실행되지 않습니다.
(3) GitHub > Settings > Pages에서 main 브랜치 / (root)를 확인합니다.
(4) 배포 후 https://parkexam.github.io/pass/ 에 접속합니다.
    파일을 PC에서 더블클릭(file://)하면 브라우저 보안 때문에 JSON을 읽지 못할 수 있습니다.

2. 등록된 내용
----------------
- 시험 분야: LEET / 간호직 / 9급 공무원
- 우선 과목: 추리논증, 간호관리, 9급 국어, 9급 영어, 지역사회간호, 9급 한국사 (6개)
- 현재 실제 등록된 시험지: 2027학년도 LEET 추리논증 40문항
- 원문 출처: 사용자 제공 2027 추리논증.pdf (20쪽 / 한 쪽에 2문제)
- 정답: 사용자 제공 2027 추리논증_정답표.hwp 기준, 40문항 전부 등록
- 해설: 제공된 문서에 없으므로 미등록 상태. 앱에서도 해설 준비 중으로 정확하게 안내합니다.

3. 폴더별 역할
----------------
index.html                      : 앱 껍데기, 다른 기능을 직접 넣지 않음
css/style.css                   : 선택한 B UI 디자인 유지
js/core.js                     : 브라우저 저장, 시험 목록 및 시험지 JSON 로딩
js/views.js                    : 홈 / 시험 선택 / 문제풀이 / 채점 결과 / 오답 화면
js/quiz.js                     : 채점과 진행 기록 처리
js/admin.js                    : 로컬 관리자 / CSV 등록 / 백업 처리
js/app.js                      : 클릭 이벤트 / 화면 렌더링

data/catalog.json               : 시험 분야 / 과목 / 시험지 인덱스

data/leet/reasoning/2027.json   : 2027 추리논증 40개 문제 및 정답 (정답 index는 0부터 시작)
assets/questions/leet/2027/     : q01.webp ~ q40.webp, 원문 문항별 그림

4. 새 시험 추가하기
-------------------
(1) data/catalog.json에 시험/과목/시험지 메타데이터 추가
(2) data/<시험>/<과목>/<연도>.json에 문제·보기·정답·해설 추가
(3) 필요한 그림이 있으면 assets/questions/...에 넣고 imageUrl로 연결
(4) JSON 파일은 dataFile 경로로 호출되므로 index.html을 바꿀 필요가 없습니다.
(5) 추리논증 2027.json의 explanation 값을 채우면 해당 문제의 오답 해설로 표시됩니다.

5. 개발판 주의사항
-------------------
- 사용자의 풀이 및 오답 기록은 현재 기기의 브라우저 localStorage에 보관됩니다.
- 기존 B 버전 저장키(EXAM_BANK_B_LOCAL_V2)를 유지하여 기존 로컬 기록을 덮어쓰지 않습니다.
- 관리자의 직접 등록 기능은 로컬 저장이며 다른 사용자에게 자동 배포되지 않습니다.
- 외부 JSON 시험지 내용은 파일을 수정한 뒤 GitHub에 재배포해야 합니다.
- 서버 인증/결제/회원별 학습 동기화는 연결되지 않았습니다.
- 공개 GitHub Pages에 올린 JSON/이미지는 모두 공개됩니다. 유료화 전에 서버에서 구독/구매 권한을 검증하도록 구조 변경이 필요합니다.
- PDF 원문 및 해설의 온라인 재배포/상업적 이용 권한은 별도 확인이 필요합니다.
