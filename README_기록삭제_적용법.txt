EXAM BANK — 선택 기록 삭제 기능 업데이트 (160문항 유지)

기능:
• 홈의 '최근 풀이' → '내가 푼 기출'
• 마이 페이지의 '전체 풀이 기록' → '내가 푼 기출 목록'
• 응시 기록을 열면 오른쪽 위 '기록 삭제'가 나타납니다.
• 삭제하면 해당 응시를 누적 풀이 문항수, 정답률, 오늘 푼 문항수에서 제외합니다.
• 해당 응시로 인해 추가된 오답은 다른 응시 기록을 대조하여 정리합니다.
• 다른 응시 기록, 문제 원본(JSON/이미지), 수동으로 남긴 다른 오답은 유지합니다.

적용 방법:
GitHub parkexam/pass 저장소에 압축을 풀고 아래 네 파일을 정확히 같은 경로에 교체하세요.
- css/style.css
- js/core.js
- js/views.js
- js/app.js
index.html 및 data/, assets/는 기존대로 유지하세요.
Commit changes 후 강력 새로고침하여 확인하세요.
중요: 삭제 후에는 이 기기에서 되돌릴 수 없으니 먼저 마이 → 데이터 백업으로 내보내기를 권장합니다.
Firebase 동기화는 아직 연결되지 않았으므로 삭제는 이 브라우저의 데이터에만 적용됩니다.
