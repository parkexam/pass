EXAM BANK — 2026-11-14 · 9개 UI/UX 요청사항 반영

1. ①~⑤ 버튼의 ‘보기’ 문구 제거.
2. 선택지별 해설(optionExplanations) 지원. 기존 140문항의 오답 선택지별 검증 해설은 미작성 상태이며, 하단 CSV 양식에 작성해 주면 나중에 JSON에 반영할 수 있습니다.
3. 문제 상단 반복 안내문 제거.
4. 원문 이미지를 새 탭 대신 앱 내부 확대창에서 표시. 상단 × 닫기, 하단 문제로 돌아가기, 확대/축소.
5. 마이 페이지 학습관리 아이콘 제거.
6. 결과 정오표의 중복 설명 문구 제거(정오표 ○/× 자체는 유지).
7. 문항별 상세 결과를 눌러 원문 이미지와 해설을 확인하고 확대 가능.
8. 홈에서 임의 기준 100% 달성률 제거. ‘오늘 푼 문항 수 N문항’으로 변경하고 일일 목표 입력은 마이 페이지에 배치.
9. 해설 화면의 반복되는 ‘자체 작성 해설 ... 검수 필요’ 첫 줄만 숨김. 검수 상태는 원본 데이터에 남아 있습니다.

기존 앱: 140문항, B UI, 타이머, 오답/채점 기록용 localStorage 키 유지.
전체 ZIP은 프로젝트 최상위에 파일과 폴더 모두 올립니다.
패치 ZIP에서는 index.html, js/views.js, js/quiz.js, js/core.js, js/app.js, css/style.css를 동일 경로에 덮어씁니다.

해설을 직접 작성할 때: 각 JSON 문항에 optionExplanations: ["1번 해설", "2번 해설", "3번 해설", "4번 해설"]와 같이 추가. LEET은 5개 작성. 빈 문자열은 화면에 표시하지 않습니다. ‘선택지별_해설_작성양식.csv’에서 문항 ID별로 쌓아갈 수 있습니다.
주의: 현재 관리자 수정 결과는 해당 브라우저에만 저장됩니다. 모든 사용자에게 공유하려면 JSON 파일을 업데이트하거나 이후 Firebase 관리자를 연결해야 합니다.
